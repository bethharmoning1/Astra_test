# GPT-6-Astra API preflight

These are infrastructure probes with a synthetic red image, not scored robot episodes. The actual production function schemas and two consecutive Responses requests with the full probe history both completed using `gpt-6-astra`, `medium`, and streaming. The initial nonstreaming request timed out and its evidence is retained. Credentials and authorization headers are excluded. Public SSE events and final responses are saved; unavailable hidden reasoning and independent backend model versions cannot be verified.

The production protocol is frozen separately in the evaluation batch configuration.
